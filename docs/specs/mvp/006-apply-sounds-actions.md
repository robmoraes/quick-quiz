# QuickQuiz Dev MVP: Run, sounds, and message theming

## Objective

Make the UI more fun and immersive by applying sounds to specific events and by
applying theming to messages.

## Sounds on Events

Apply sounds in the UI triggered by the following events:

**Correct answer**: frontend/src/assets/sounds/question-passed.mp3

**Wrong answer**: frontend/src/assets/sounds/question-failed.mp3

**Complete a Run**: frontend/src/assets/sounds/run-complete.mp3

## Answer Theme

The theme for wrong and correct answers will be: **unit tests**; The written
messages for correct and wrong answers must be equivalent to messages from the
end of a unit test execution.
